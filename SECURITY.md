# Security policy

Only the latest release of each CrabXL package receives security fixes.

Do not report a vulnerability in a public issue. Use GitHub private
vulnerability reporting in the affected repository: open its **Security** tab
and select **Report a vulnerability**. For the libraries, use
[crabxl](https://github.com/crabxl/crabxl/security/advisories/new) or
[crabxl-python](https://github.com/crabxl/crabxl-python/security/advisories/new).

We will reply in the advisory. When a fix is available, we publish a release
and the advisory.
